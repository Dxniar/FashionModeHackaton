# User flows (MVP)

## CLIENT (B2C)

1. Login.
2. Открывает витрину.
3. Выбирает товар:
   - in-stock: купить,
   - preorder: указывает дату готовности.
4. Создает заказ.
5. Следит за прогрессом по этапам: `PLACED → SEWING → DONE`.

## FRANCHISEE (B2B)

1. Login.
2. Видит новый заказ в списке/канбане без refresh.
3. Переводит заказ в `IN_PROGRESS`.
4. Передает в цех (`SEWING`).

## PRODUCTION (Workshop)

1. Login на планшете.
2. В очереди отображаются задачи со статусом `SEWING`.
3. Открывает активную задачу.
4. Нажимает **ЗАВЕРШИТЬ**.
5. Статус меняется на `DONE`, клиент видит обновление.
