# Тестовый сценарий для презентации

## Подготовка

- 3 тестовых пользователя в Firebase Auth:
  - `client@avishu.demo` (CLIENT)
  - `franchisee@avishu.demo` (FRANCHISEE)
  - `production@avishu.demo` (PRODUCTION)
- Запустить приложение на 3 устройствах/эмуляторах.

## Сквозной сценарий (2-3 минуты)

1. Клиент создает заказ (in-stock или preorder).
2. На экране франчайзи заказ появляется автоматически.
3. Франчайзи переводит заказ в `IN_PROGRESS`, затем `SEWING`.
4. В цеховом интерфейсе появляется задача.
5. Швея нажимает `ЗАВЕРШИТЬ`.
6. Клиентский экран автоматически меняет статус на `DONE`.

## Чек-лист приемки

- [ ] Нет ручного обновления страницы.
- [ ] Статус меняется во всех ролях почти мгновенно.
- [ ] Роли не видят чужие приватные данные.
- [ ] UI соответствует AVISHU (ч/б, минимализм, upper-case).

## Pitсh-тезисы (1 минута)

- «Бизнес в кармане»: одна экосистема для клиента, франчайзи и производства.
- Real-time прозрачность снижает операционные потери и ускоряет цикл заказа.
- Приложение — IT-актив, повышающий ценность франшизы.
